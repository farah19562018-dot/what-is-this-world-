# What Is This World?
## Run it on Windows
No installation needed. Open the folder and double-click `index.html`. It opens in your browser.
## Add an article
Open `articles.js` in Notepad, copy one article block, paste it after the last one (add a comma), change the text and a new unique `slug`.
## Change images
Put a photo in a folder called `images`, then add `img:"images/photo.jpg"` to that article. Without it, a colour cover is used.
## Edit categories
Edit the CATEGORIES list at the top of `articles.js`.
## Status
Works: navigation, search and suggestions, favorites (saved in browser), category sorting, share/copy link, profile (demo).
Needs setup: real sign-in (needs a backend service), real photos, a public domain/hosting.
